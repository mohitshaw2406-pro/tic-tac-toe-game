# Tic Tac Toe Game 🎮

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features
- Two-player game
- Turn indicator
- Win highlight
- Draw detection
- Score counter
- Reset & New Game options

## Technologies Used
- HTML
- CSS
- JavaScript
